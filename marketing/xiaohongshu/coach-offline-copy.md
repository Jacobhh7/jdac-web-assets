## 正文（簡體，直接複製貼上）

```
上周有个学生问我：「老师，我练了三年，为什么还是只会那几个节奏？」

我让他打八小节最基本的八分音符。
第三小节右手开始往下压，第五小节肩膀跟着抬，到第七小节速度自己快了两格——他完全没感觉。

这不是天分的问题，是没人在旁边看着改。

线上课我教很多年了，该练什么、按什么顺序练、该学什么歌，这套系统是有效的，我也一直在用。
但有些东西真的隔着萤幕看不到：

· 你握棒的支点到底在哪根手指
· 棒子落下去之后，是「弹回来」还是被你硬拉回来
· 打快的时候，是手在动，还是整条手臂在撑

这几件事，我在你旁边坐十分钟，能省你半年。

所以这次我在上海开一对一实体课。
不是大班、不是讲座，就是你、我、一套鼓。
来之前先跟我说你卡在哪，我就把那段时间全部花在那件事上。

先说清楚：我不会跟你保证「几堂课学会某首歌」，那种话我讲不出口。
我能保证的是，你走的时候会知道接下来三个月要练什么、为什么练。

先把地基打稳，炫技才有意义。
我自己超爱玩花里胡哨的东西，但那些全都是踩在基本功上面，才做得出来的。

—
评论区跟我说：你卡最久的是哪一关？
写「速度上不去」「过门乱掉」「跟不上歌」都行，我一则一则回。
想约课的私信我「实体课」三个字，我把档期发你。

#爵士鼓 #架子鼓 #学打鼓 #上海爵士鼓 #成人学乐器 #零基础学鼓 #打鼓入门 #上海一对一 #鼓手日常 #基本功
```

## 正文（繁體，你自己看的版本）

```
上週有個學生問我：「老師，我練了三年，為什麼還是只會那幾個節奏？」

我讓他打八小節最基本的八分音符。
第三小節右手開始往下壓，第五小節肩膀跟著抬，到第七小節速度自己快了兩格——他完全沒感覺。

這不是天分的問題，是沒人在旁邊看著改。

線上課我教很多年了，該練什麼、按什麼順序練、該學什麼歌，這套系統是有效的，我也一直在用。
但有些東西真的隔著螢幕看不到：

· 你握棒的支點到底在哪根手指

這幾件事，我在你旁邊坐十分鐘，能省你半年。

所以這次我在上海開一對一實體課。

想約課的私訊我「實體課」三個字，我把檔期發你。
```

## 首評／私訊回覆的話術（統一口徑）

- 問價格 → 「档期跟价格我私信发你，先跟我说一下你现在打多久了、卡在哪，我看要不要排给你。」
- 問線上還線下 → 「线上课是完整系统，实体课是来修那些线上看不到的手部细节，两个不冲突，多数人是先线上再来面对面调一次。」
- 非上海 → 「这次只在上海。你在哪个城市？我记一下，之后排城市会看留言。」
