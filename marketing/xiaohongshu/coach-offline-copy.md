## 正文（簡體，直接複製貼上）

```
「老师，我练了三年，为什么还是只会那几个节奏？」

这句话我这几年听了太多次。

我通常不回答，我让他打八小节最基本的八分音符。
第三小节右手开始往下压，第五小节肩膀跟着抬，到第七小节速度自己快了两格——他完全没感觉。

不是天分问题，是没人在旁边看着改。

线上课我做很多年了，该练什么、按什么顺序练、什么时候可以开始学歌，这套系统是有效的，我到现在还在用。
但有三件事，隔着屏幕真的看不到：

01 握棒的支点，到底在哪根手指
02 棒子落下去，是弹回来，还是被你硬拉回来
03 打快的时候，是手在动，还是手臂在硬撑

这三件事，我坐你旁边十分钟，能省你半年。

所以我人现在在上海，一对一实体课已经在上了。
不是大班、不是讲座，就是你、我、一套鼓。
来之前先跟我说你卡在哪，我就把那段时间全部花在那件事上。

先说清楚：我不会跟你保证「几堂课学会某首歌」，那种话我讲不出口。
我能保证的是，你走的时候会知道接下来三个月要练什么、为什么练。

先把地基打稳，炫技才有意义。
我自己超爱玩花里胡哨的东西，但那些全都是踩在基本功上面，才做得出来的。

—
评论区跟我说：你卡最久的是哪一关？
写「速度上不去」「过门乱掉」「跟不上歌」都行，我一则一则回。
想上课的私信我「实体课」三个字，我把档期发你。

#爵士鼓 #架子鼓 #学打鼓 #上海爵士鼓 #成人学乐器 #零基础学鼓 #打鼓入门 #上海一对一 #鼓手日常 #基本功
```

## 私訊／留言統一口徑

- **問價格** → 「档期跟价格我私信发你。先跟我说一下你打多久了、卡在哪，我看排哪个时段给你比较有用。」
- **問線上還線下** → 「线上课是完整系统，实体课是来修那些线上看不到的手部细节，两个不冲突。多数人是先线上，再来面对面调一次。」
- **不在上海** → 「这阵子人在上海。你在哪个城市？我记一下，之后排城市会看留言。」
- **完全零基础** → 「零基础更该来。手的习惯还没长歪，这时候调最省事。」
